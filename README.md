# pattern-recognition-term-project

1. Put models .pt with name `cosface_best.pt` in `model/checkpoints/`

2. Run with docker

```bash
docker-compose up --build
```
The main page will be at http://localhost:8000.

The admin page will be at http://localhost:8000/admin/.
By default, superuser will be created with username `admin@example.com` and password `admin123`.
